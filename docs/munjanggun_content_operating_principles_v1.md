# 문장군 콘텐츠 운영 원칙 v1.0

작성일: 2026-06-19

## 문서의 위치

이 문서는 문장군 리뷰릴스엔진, 블로그엔진, 캐러셀엔진이 공통으로 따르는 상위 콘텐츠 철학입니다.

각 엔진별 제작 규칙, QA, 템플릿, 발행 기준은 이 문서 아래에 놓입니다.

## 목적

문장군 콘텐츠의 목적은 중문을 설명하는 것이 아닙니다.

문장군을 홍보하는 것도 아닙니다.

제품 스펙을 소개하는 것도 아닙니다.

문장군 콘텐츠의 목적은 고객이 자신의 문제를 발견하게 만드는 것입니다.

사람은 중문에 관심이 없습니다.

사람은 소음에 관심이 있고, 반려동물에 관심이 있고, 아이 안전에 관심이 있고, 후회 없는 선택에 관심이 있습니다.

우리는 중문을 판매하는 회사지만 콘텐츠에서는 중문을 먼저 판매하지 않습니다.

고객의 문제를 보여주고, 그 문제의 해결 과정을 보여줍니다.

## 핵심 원칙

### 원칙 1. 정보보다 사건을 우선한다

잘못된 접근:

- 중문 종류 설명
- 중문 장점 설명
- 중문 가격 설명

올바른 접근:

- 고양이가 현관으로 탈출했다
- 시공을 포기할 뻔한 현장이 있었다
- 입주 후 고객이 가장 후회한 선택이 있었다

사람은 정보를 소비하지 않습니다.

사람은 사건을 소비합니다.

### 원칙 2. 후킹은 정보가 아니라 자기 연관성이다

콘텐츠를 본 고객이 "그래서?"라고 생각하면 실패입니다.

"고객 이야기"가 아니라 "내 이야기"처럼 느껴져야 합니다.

모든 콘텐츠는 고객 자신의 상황과 연결되어야 합니다.

### 원칙 3. 문제를 먼저 보여주고 해결은 나중에 보여준다

사람은 해결책보다 문제에 먼저 반응합니다.

따라서 기본 구성은 아래 순서입니다.

```text
문제
-> 공감
-> 긴장
-> 해결
```

금지 구성:

```text
제품
-> 설명
-> 장점
```

## 문장군 콘텐츠 공식

```text
사건
-> 공감
-> 반전
-> 해결
-> 결과
```

## 조회수가 나오는 콘텐츠

- 사건이 있다
- 문제가 있다
- 궁금증이 있다
- 결과가 있다

## 조회수가 안 나오는 콘텐츠

- 제품 설명
- 시공 설명
- 회사 자랑
- 기능 설명
- 가격 설명

## 절대 금지

아래 문장은 고객이 관심 없는 회사 중심 표현입니다.

- 우리는 최고입니다
- 우리는 전문입니다
- 우리는 잘합니다
- 우리는 15,000건 했습니다

고객은 항상 이렇게 생각합니다.

```text
그래서 내 문제와 무슨 상관인데?
```

## 고객이 궁금한 것

모든 콘텐츠는 아래 질문 중 하나 이상을 해결해야 합니다.

- 내가 후회할까?
- 내가 손해 볼까?
- 우리 집도 가능할까?
- 반려동물은 안전할까?
- 소음은 줄어들까?
- 왜 다른 집은 설치할까?

## 콘텐츠 품질 평가 기준

각 항목은 0~5점으로 평가합니다.

| 항목 | 질문 |
|---|---|
| 사건성 | 사건이 존재하는가 |
| 자기 연관성 | 고객이 자신의 이야기로 느끼는가 |
| 궁금증 | 다음 내용을 보고 싶어지는가 |
| 공감 | 실제 경험처럼 느껴지는가 |
| 해결 | 명확한 해결이 존재하는가 |

총점은 25점입니다.

20점 미만 콘텐츠는 발행하지 않습니다.

## 리뷰릴스 총괄 운영 원칙

### 리뷰는 증거가 아니라 사건 데이터다

리뷰는 단순 증거가 아닙니다.

리뷰는 고객이 겪은 사건 데이터입니다.

우리는 리뷰를 읽고 고객이 왜 리뷰를 썼는지 찾습니다.

### 리뷰에서 찾아야 하는 것

- 갈등
- 불편
- 후회
- 고민
- 놀람
- 감동

### 좋은 소재와 나쁜 소재

좋은 소재:

```text
고양이가 자꾸 현관으로 나갔어요
```

나쁜 소재:

```text
3연동 중문 설치했습니다
```

### 리뷰릴스 공식

```text
사건
-> 문제 확대
-> 반전
-> 해결
-> 고객 반응
```

### 리뷰릴스 하드 원칙

후킹은 제품명이 아니라 사건으로 시작합니다.

나쁜 훅:

```text
3연동 중문 설치 후기
```

좋은 훅:

```text
고양이 한 마리가 이 집을 바꿨습니다
```

### 리뷰릴스 KPI

- 시청 유지율
- 완주율
- 저장률
- 공유율

조회수는 결과 지표입니다.

조회수만 보지 않습니다.

## 블로그·캐러셀 총괄 운영 원칙

### 블로그와 캐러셀의 목적

검색 노출이 목적이 아닙니다.

설득이 목적입니다.

### 블로그 공식

```text
문제 제기
-> 공감
-> 사례
-> 해결
-> 결론
```

### 캐러셀 공식

```text
1장: 문제
2장: 문제 확대
3~5장: 원인
6~8장: 해결
마지막: 행동 유도
```

## 문장군 콘텐츠의 경쟁력

문장군 콘텐츠의 경쟁력은 중문 지식이 아닙니다.

현장 데이터입니다.

문장군은 아래 자산을 가지고 있습니다.

- 실측 데이터
- 고객 후기
- 시공 사례
- 실패 사례
- 고민 사례

이것이 경쟁사와의 차별점입니다.

## 앞으로의 콘텐츠 방향

- 스펙 중심 콘텐츠 감소
- 사건 중심 콘텐츠 확대
- 제품 중심 콘텐츠 감소
- 고객 중심 콘텐츠 확대
- 설명형 콘텐츠 감소
- 스토리형 콘텐츠 확대

## 최종 목표

중문에 관심 없는 사람도 끝까지 보는 콘텐츠를 만듭니다.

그 결과로 문장군을 신뢰하게 만듭니다.

그 결과로 문의가 발생합니다.

## 대표 요약

```text
문장군 콘텐츠는 중문을 설명하는 콘텐츠가 아니라,
고객의 문제와 사건을 보여주는 콘텐츠로 전환한다.
```
