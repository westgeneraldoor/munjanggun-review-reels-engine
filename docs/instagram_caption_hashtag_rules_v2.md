# 문장군 인스타 캡션/해시태그 규칙 v2

이 문서는 리뷰엔진이 숏폼 HTML/MP4 이후 인스타그램 발행 문안까지 자동 생성할 때 적용하는 기준입니다.

## 캡션 구조

캡션은 최소 기준 통과용 요약이 아니라 발행용 본문입니다.

1. 첫 줄은 문제 상황 + 내 이야기인지 묻는 훅으로 시작합니다.
2. 본문은 원문 리뷰의 구체 포인트를 2개 이상 사용합니다.
3. 변화는 과장하지 않고 체감, 후기, 가능 여부 확인 중심으로 씁니다.
4. 마지막은 저장 이유와 무료 실측/방문 실측 CTA로 마무리합니다.
5. 길이는 6~9줄을 기본으로 합니다.

## 금지 표현

- "이 리뷰를 참고해보세요"처럼 얕은 요약
- "완벽 차단", "무조건 해결"처럼 보장형 표현
- 원문 리뷰에 없는 효과 과장
- 가격, 기간, 추가금 관련 단정 표현

## 해시태그 구조

해시태그는 20~25개를 기본으로 하며, 모두 `#붙여쓰기` 형태로 작성합니다.

필수 브랜드 태그:

`#문장군 #문장군중문 #문장군시공`

권장 조합:

- 브랜드 3개
- 제품/시공 5~7개
- 문제상황 5~7개
- 고객상황/행동유도 5~8개

## 예시 톤

좋은 첫 줄:

`에어컨을 계속 틀어도 거실이 시원해지지 않는다면, 현관 쪽 공기 흐름을 한 번 의심해볼 만합니다.`

좋은 CTA:

`무료 방문 실측으로 우리 집은 어떤 방식이 가능한지 먼저 확인할 수 있습니다.`

좋은 해시태그 묶음:

`#문장군 #문장군중문 #문장군시공 #현관중문 #중문시공 #구축리모델링 #현관소음 #무료실측 #방문실측`
