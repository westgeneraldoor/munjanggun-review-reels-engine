# 리뷰 릴스 엔진 브랜드 어댑터

중앙 원본은 문장군이 무엇을 말할지 정하고, 이 프로젝트는 그것을 리뷰 릴스로 안전하게 만드는 방법을 정한다.

- 제품 설명보다 고객 문제와 사건을 먼저 보여준다.
- 리뷰 원문에 없는 불편, 감정, 수치, 강한 claim을 사실처럼 쓰지 않는다.
- 첫 프레임은 훅의 실제 고객 사진 근거이며, 리뷰 캡처는 가짜 카드가 아닌 실제 증거로만 쓴다.
- 최종 TTS가 시간축이고, HTML/MP4 전 `reels_qa` strict contract와 sync manifest를 통과해야 한다.
- `사진 다 넣었어. HTML까지 가자`는 HTML까지만 일괄 승인한다. MP4는 별도 승인이다.

상세 실행 계약은 `../review_reels_one_shot_contract_v1.md`를 단일 권위로 참조한다.
