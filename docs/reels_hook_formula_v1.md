# 문장군 리뷰 릴스 후킹 공식 v1

작성일: 2026-06-19

## 목적

이 문서는 문장군 리뷰 릴스의 첫 1~3초 훅을 감으로 쓰지 않고, 반복 가능한 공식으로 만들기 위한 기준입니다.

좋은 훅은 단순히 궁금한 문장이 아니라 시청자의 심리 방어선을 흔드는 트리거 조합입니다.

## 6가지 후킹 트리거

| 트리거 | 의미 | 문장군 적용 |
|---|---|---|
| 호기심 결핍 | 일부 정보를 비워 시청자가 다음 장면을 보게 함 | 이 구조, 이것, 진짜 이유 |
| 구체적 숫자 | 막연한 주장보다 구체성을 만듦 | 30분 실측, 두 곳 시공, 한 달 후기 |
| 타깃 호명 | 특정 시청자를 직접 부름 | 구축집, 반려견 집, 로봇청소기 쓰는 집 |
| 통념 반박 | 당연한 믿음을 뒤집음 | 비싼 중문이 좋은 중문은 아닙니다 |
| 손실 회피 | 놓치면 손해라는 감정을 건드림 | 설치 전 이 구조 놓치면 후회합니다 |
| 결과 약속 | 보면 얻을 결과를 먼저 제시 | 집 분위기가 달라진 이유 |

## 문장군 우선 조합

문장군 리뷰 릴스에서는 아래 조합을 우선합니다.

### 1. 현장 문제 + 통념 반박

```text
중문 소음은 문 때문이 아닐 수 있습니다
비싼 중문보다 중요한 건 현장 실측입니다
3연동중문, 제품보다 먼저 봐야 할 게 있습니다
```

### 2. 손실 회피 + 호기심

```text
입주 전에 이 구조 놓치면 후회합니다
중문 설치 전, 이 틈새를 먼저 봐야 합니다
현관 구조 하나 때문에 결과가 달라집니다
```

### 3. 타깃 호명 + 문제

```text
구축 빌라 사는 분들, 현관 소리 그냥 두지 마세요
로봇청소기 쓰는 집이라면 문턱부터 봐야 합니다
반려견이 복도 소리에 예민하다면 이 구조를 보세요
```

## 금지와 제한

자극적인 훅이어도 원문 리뷰와 현장 자료를 배신하면 실패입니다.

- 숫자 훅은 실제 리뷰, 실측, 사진, 시공자료에 근거가 있을 때만 사용합니다.
- 근거 없는 `40% 감소`, `100% 차단`, `완벽 방음`은 금지합니다.
- 고객이 말하지 않은 감정은 실제 감정처럼 쓰지 않습니다.
- 원문에 없는 소음, 냄새, 먼지, 반려동물, 아이, 공사난이도 소재를 훅에 넣지 않습니다.
- 근거 없는 숫자는 `작은 차이`, `몇 cm 차이`, `현장 조건 하나`처럼 완화합니다.

## 작가 산출물 기준

작가는 훅 후보 3개 이상을 만들 때 각 훅에 트리거를 붙입니다.

```json
{
  "hook_candidates": [
    {
      "text": "비싼 중문이 좋은 중문은 아닙니다",
      "triggers": ["counter_belief"],
      "source_evidence": "원문 가격 만족/시공 만족 표현"
    },
    {
      "text": "입주 전에 이 구조 놓치면 후회합니다",
      "triggers": ["loss_aversion", "curiosity_gap"],
      "source_evidence": "사진 속 현관 구조/실측 자료"
    }
  ]
}
```

## QA 기준

최종 선택 훅은 HTML 생성 전 최소 1개 이상의 트리거를 가져야 합니다.

통과:

```text
비싼 중문이 좋은 중문은 아닙니다
입주 전에 이 구조 놓치면 후회합니다
금요일 실측, 수요일 시공까지
```

실패:

```text
중문 설치 후기입니다
좋아졌습니다
만족도가 높았습니다
설치한 집
```

## 최종 원칙

문장군 후킹은 자극적이어야 하지만 거짓이면 안 됩니다.

좋은 훅은 시청자를 멈추게 만들고, 좋은 QA는 원본 리뷰를 배신하지 않게 막습니다.
