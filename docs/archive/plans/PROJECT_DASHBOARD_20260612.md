## 운영 규칙

- 리뷰를 추가/정리하면 이 대시보드도 같은 턴에 갱신한다.
- 리뷰 추가 작업은 파일 저장, 1차 채점, 후보 선별, 배치 기록, 대시보드 갱신, 문맥 갱신, 무결성 검증까지 끝나야 완료다.
- 패키지를 생성하면 콘텐츠 패키지 현황 수량도 갱신한다.
- `PROJECT_DASHBOARD.md`는 새 세션의 첫 현황판이다. 오래된 숫자를 남기지 않는다.
- `033 리뷰 릴스 만들자`처럼 번호가 있어도 HTML 제작으로 직행하지 않는다. 사진검수/작가 브리프/PD 기획안/scene 의미 일치 계획을 먼저 제시하고 사용자 승인 후 제작한다.

- 다음 후보군이 3개 미만이면 미제작 A/B권 리뷰에서 후보를 보충하고, 사용자가 바로 사진을 넣을 수 있도록 output 패키지 폴더와 이미지 폴더를 미리 만든다.
