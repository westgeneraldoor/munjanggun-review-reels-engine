# 실무 팁 (중요)

씬 이름만 저장하지 말고 반드시 메타데이터화:

```yaml
scene: dashboard_showcase
best_for: [saas]
arc_step: [proof]
emotion: [trust,premium]
duration: [3,6]
energy: medium
conversion_score: 9.1
```

이래야 AI가 자동 선택 가능.
