# Munjanggun Video Templates v2

This document defines the first five performance-oriented short-form templates for the Munjanggun review engine.

Each template must create a different viewing experience, not just different captions over the same motion style.

## Shared Rules

- First two seconds must use a complete hook sentence.
- The video recipe is the source of truth.
- Review capture is evidence; review quote is readable copy.
- CTA gets its own final scene.
- Avoid unsupported absolute claims.
- Keep v1 review-story videos, but generate v2 variants separately.

## Purpose Presets

| Purpose | Target Length | CTA | Review Proof |
|---|---:|---|---|
| `ad` | 20-25s | direct but not pushy | quote first, capture behind |
| `feed_trust` | 25-35s | soft | capture + context |
| `retargeting` | 20-30s | direct | quote + result shot |
| `brand_expertise` | 25-35s | consultative | process + review |
| `story_highlight` | 15-25s | light | one-line proof |

# 1. Cooling Effect

## Purpose

Seasonal ad creative for people who feel summer cooling inefficiency.

## Use Conditions

Use when review mentions:

- 에어컨
- 여름
- 덥다
- 시원해졌다
- 냉방 효율
- 현관 쪽 열기 or 공기 흐름

Useful image roles:

- before entry/hall
- after installed middle door
- product thumbnail
- review capture

## Representative Hooks

1. 문제 공감형: `에어컨 풀가동해도 거실이 덥다면?`
2. 궁금증 유발형: `중문 하나로 냉방 체감이 달라질 수 있을까?`
3. 체감 변화형: `더운 공기 들어오던 현관, 이렇게 바뀌었습니다`

Best ad hook:

```text
에어컨 풀가동해도 거실이 덥다면?
```

Reason: broad seasonal pain, immediately self-relevant, clear curiosity.

## Recommended Length

- ad: 20-23s
- feed trust: 25-30s

## Timeline Structure

```text
0-2s   hook
2-6s   problem: heat/air flow from entrance
6-10s  solution: installed middle door
10-16s before_after: changed room feeling
16-20s review_proof: readable quote over review capture
20-23s cta
```

## Scene Roles

| Role | Visual |
|---|---|
| hook | before or entry angle |
| problem | before, hallway, entrance |
| solution | product thumbnail or first after shot |
| before_after | before and after shots |
| review_proof | blurred review capture + quote |
| cta | clean after shot |

## Narration Tone

Practical and sensory. Avoid technical over-explanation.

Good:

```text
에어컨을 세게 틀어도 거실이 덥다면, 현관 쪽 공기 흐름부터 확인해볼 필요가 있습니다.
```

## Caption Tone

Yellow/white with cool glow. Use fewer warning colors.

## Review Proof

Extract a quote such as:

```text
“에어컨 켜니 확실히 더 시원해졌어요”
```

Use only if supported by review meaning.

## CTA Examples

```text
우리 집도 가능할까?
무료 방문 실측 상담
```

```text
사진만 보고 고민하지 말고
현장에서 먼저 확인하세요
```

## Avoid

- `완벽 차단`
- `냉방비 무조건 절약`
- unsupported energy-saving claims

# 2. Old Building Noise

## Purpose

Conversion-oriented creative for old villas, old apartments, corridor-style homes, noise, smell, dust, and entrance discomfort.

## Use Conditions

Use when review mentions:

- 구축
- 빌라
- 복도 소리
- 현관 소음
- 냄새
- 먼지
- 외풍
- 소음 차단

Useful image roles:

- before entrance
- building exterior
- stair/corridor path
- measurement
- after installed door
- review capture

## Representative Hooks

1. 문제 공감형: `복도 소리 다 들리는 구축 빌라라면?`
2. 궁금증 유발형: `현관문 하나 사이로 냄새까지 들어온다면?`
3. 체감 변화형: `소음·냄새 체감이 달라진 중문 시공`

Best ad hook:

```text
복도 소리 다 들리는 구축 빌라라면?
```

## Recommended Length

- ad: 22-25s
- retargeting: 23-28s
- feed trust: 28-32s

## Timeline Structure

```text
0-2s   hook
2-6s   pain: corridor noise/smell/dust
6-10s  context: old building route/exterior/stairs
10-15s solution: measurement and installation
15-20s before_after/result
20-23s review quote
23-25s cta
```

## Scene Roles

| Role | Visual |
|---|---|
| hook | before entrance or hallway |
| pain | stairs/corridor/exterior |
| context | old building route |
| solution | measurement/product |
| before_after | after main/open/detail |
| review_proof | review capture + quote |
| cta | clean after shot |

## Narration Tone

Empathetic and specific. The viewer should think, "This is my house."

## Caption Tone

Bold yellow for pain. Controlled darkening only when emphasizing discomfort.

## Review Proof

Use quote fragments:

```text
“소음이 덜 신경 쓰여요”
“냄새 유입이 줄어든 느낌이에요”
```

Only if the review supports them.

## CTA Examples

```text
구축 빌라도 가능할까?
무료 방문 실측으로 확인하세요
```

## Avoid

- `완벽 차단`
- guaranteed soundproofing
- medical/health claims about smell/dust

# 3. Difficult Installation

## Purpose

Brand expertise and trust content. Can be used for retargeting or profile credibility.

## Use Conditions

Use when review mentions:

- 다른 업체 포기
- 어려운 시공
- 주차 어려움
- 자재 이동
- 추가요금
- 직접 설명
- 꼼꼼한 시공

Strong image roles:

- exterior
- entrance
- stairs
- measurement
- construction-in-progress
- after details
- review capture

## Representative Hooks

1. 문제 공감형: `다른 업체가 포기한 현장, 정말 안 될까?`
2. 궁금증 유발형: `“여긴 어렵다”던 현장, 어떻게 끝냈을까요?`
3. 전문성형: `포기한 현장도 직접 보고 방법을 찾았습니다`

Best trust hook:

```text
“여긴 어렵다”던 현장, 어떻게 끝냈을까요?
```

Best direct hook:

```text
다른 업체가 포기한 현장, 문장군은 시공했습니다
```

## Recommended Length

- brand expertise: 27-32s
- retargeting: 24-28s
- ad: only if compressed to 23-27s

## Timeline Structure

```text
0-2s    hook: difficult site
2-6s    obstacle: parking/material/stairs/exterior
6-10s   problem: others gave up or asked extra cost
10-15s  proof: measurement and direct explanation
15-20s  process: construction-in-progress
20-25s  mission clear: finished install/detail
25-29s  review proof + soft CTA
```

## Scene Roles

| Role | Visual |
|---|---|
| hook | exterior/entrance/stairs |
| obstacle | route photos |
| proof | measurement photos |
| process | construction-in-progress |
| mission_clear | final after shots |
| review_proof | capture + quote |
| cta | consultative final line |

## Narration Tone

Documentary and confident. Do not sound like bragging.

## Caption Tone

Use three-tone system:

- red: obstacle/rejection
- cyan: proof/measurement
- green/yellow: mission clear

## Review Proof

Prefer trust/expertise quote:

```text
“설명도 자세했고 시공도 꼼꼼했어요”
```

## CTA Examples

```text
어려운 현장도
먼저 실측해드립니다
```

```text
가능한 구조인지
현장에서 먼저 확인하세요
```

## Avoid

- `추가요금 걱정 끝` as absolute copy
- promising no extra cost in all cases
- mocking other companies

# 4. Living Installation

## Purpose

Reduce anxiety for people who are already living in the home and worry about dust, time, mess, or inconvenience.

## Use Conditions

Use when review mentions:

- 살면서 시공
- 거주중
- 이사 전/후
- 빠른 시공
- 깔끔한 마감
- 정리
- 불편함 적음

Useful image roles:

- lived-in before photo
- protected work area
- construction/process photo
- clean after photo
- detail photo
- review capture

## Representative Hooks

1. 문제 공감형: `살고 있는 집에 중문 시공, 괜찮을까?`
2. 궁금증 유발형: `이사 안 하고도 이렇게 바뀔 수 있습니다`
3. 안심형: `걱정했던 거주중 시공, 생각보다 깔끔했습니다`

## Recommended Length

- ad: 20-25s
- feed trust: 25-32s

## Timeline Structure

```text
0-2s   hook: living installation concern
2-6s   concern: mess/time/noise
6-10s  process: work/protection/detail
10-16s result: clean after
16-20s review quote
20-24s cta
```

## Caption Tone

Warm, reassuring, less aggressive.

## Review Proof

Use quote about cleanliness, kindness, or convenience.

## CTA Examples

```text
살고 있는 집도 가능할까?
무료 방문 실측 상담
```

## Avoid

- promising zero dust/noise
- overusing dramatic warning effects

# 5. Cost Concern

## Purpose

Answer price anxiety and reduce hesitation without making unsupported discount claims.

## Use Conditions

Use when review mentions:

- 비용
- 추가금
- 박람회
- 반값
- 무료 견적
- 상담
- 합리적
- 고민

Useful image roles:

- product thumbnail
- measurement
- before/after
- review capture
- quote about consultation or price satisfaction

## Representative Hooks

1. 문제 공감형: `중문 가격, 괜히 비쌀까 봐 망설였다면?`
2. 궁금증 유발형: `우리 집 중문, 얼마가 적당할까요?`
3. 상담형: `사진만 보고 가격 고민하지 마세요`

## Recommended Length

- ad: 20-25s
- retargeting: 18-23s

## Timeline Structure

```text
0-2s   hook: cost concern
2-5s   hesitation
5-9s   free measurement/consultation
9-15s  product/result
15-19s review quote
19-23s cta
```

## Narration Tone

Calm and transparent. Emphasize "check first", not "cheapest".

## Caption Tone

Trust blue/white/yellow, avoid red unless warning about guessing.

## Review Proof

Use consultation, quote clarity, or satisfaction quote.

## CTA Examples

```text
사진만 보고 고민하지 말고
현장에서 먼저 확인하세요
```

```text
우리 집 견적은?
무료 방문 실측 상담
```

## Avoid

- guaranteed lowest price
- fake discount urgency
- unverified "no extra cost" promises

# Template Selection Rules

## Keyword Signals

| Keyword Signal | Template |
|---|---|
| 에어컨, 여름, 냉방, 덥다 | cooling_effect |
| 구축, 소음, 냄새, 먼지, 복도 | old_building_noise |
| 어려운 시공, 포기, 주차, 자재 | difficult_installation |
| 거주중, 살면서, 깔끔, 정리 | living_installation |
| 비용, 추가금, 견적, 박람회 | cost_concern |

## Asset Signals

| Asset Pattern | Template Boost |
|---|---|
| `시공중` exists | difficult_installation +3 |
| `현장_계단`, `현장_외관`, `현장_입구` all exist | difficult_installation +2 |
| many before/after but no process | cooling or noise +1 |
| review mentions 상담/견적 and product thumbnail exists | cost_concern +2 |

## Purpose Priority

If the same review fits multiple templates:

1. If seasonal public pain exists, prefer ad template.
2. If difficult process evidence exists, prefer brand expertise or retargeting.
3. If review is mostly kindness/consultation, choose feed trust or cost concern.

## Output Variants

Each review can produce more than one video:

```text
005 cooling:
  - ad_v2: 20-23s
  - feed_v2: 27s review story

004 difficult:
  - trust_v2: 29s brand expertise
  - retargeting_v2: 24s compressed proof

010 old building:
  - ad_v2: 23-25s
  - retargeting_v2: 20-23s
```
